# Frontend UI (Work in Progress)

This directory will house the user interface for the procurement RAG assistant.

## Planned Implementation
* A Streamlit or React application where users can type natural language queries (e.g., "I need a PVC pipe for water") or upload Bill of Quantities (BoQ) documents.
* Will communicate exclusively with the FastAPI backend endpoints to retrieve and display standard-compliant tender clauses and QCO alerts.
